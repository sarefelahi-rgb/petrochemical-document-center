# مرکز هوشمند اسناد و نقشه‌های پتروشیمی

سامانهٔ تحت‌وب سازمانی برای مدیریت چرخهٔ حیات کامل اسناد و نقشه‌های مهندسی در پروژه‌های پتروشیمی — از آپلود و پردازش OCR فارسی/انگلیسی تا کنترل سند، جریان بازبینی و تأیید، و پرس‌وجوی هوشمند از محتوای اسناد با دستیار هوش مصنوعی.

## ✨ امکانات کلیدی

- **دستیار هوش مصنوعی (صفحهٔ اول سامانه):** رابط گفتگومحور به سبک چت با سایدبار سوابق مکالمات، پاسخ‌های مستند به اسناد با ذکر استناد، جست‌وجو در محتوای اسناد داخلی و بیرونی
- **آپلود و دریافت امن:** اعتبارسنجی نوع و محتوای فایل (PDF، DOCX، تصاویر)، قرنطینهٔ فایل‌های مشکوک، تشخیص نوع واقعی فایل
- **خط پردازش OCR:** OCR فارسی (fas) و انگلیسی (eng) مبتنی بر Tesseract، تولید مشتقات (بندانگشتی، تصویر صفحه، کلمات با مختصات)، تشخیص بلوک عنوان (Title Block) نقشه‌ها
- **مرکز اسناد:** ساختار درختی پروژه، نسخه‌بندی بازبینی‌ها، مقایسهٔ نسخه‌ها، علائم‌گذاری و حاشیه‌نویسی روی صفحات، جست‌وجوی متنی داخل سند
- **کنترل سند و MDR:** شماره‌گذاری و کدگذاری اسناد، ماتریس وضعیت اسناد، گزارش MDR (Master Document Register)
- **جریان بازبینی و تأیید:** کارتابل وظایف، صف بازبینی، پنل تأیید، MTO (ماتریس موارد تحویلی)، ترنسمیتال‌ها
- **بستهٔ تحویل (Dossier):** تجمیع و انتشار بستهٔ اسناد تحویلی
- **گزارش‌ها:** داشبورد گزارش‌های پروژه با نمودارها
- **مدیریت سامانه:** مدیریت کاربران و نقش‌ها، واژگان تخصصی (Vocabulary)، دادهٔ نمونه، لاگ حسابرسی (Audit)، تنظیمات شامل فعال/غیرفعال‌سازی ورود دومرحله‌ای (MFA/TOTP)
- **RTL کامل:** رابط فارسی راست‌به‌چپ با فونت وزیرمتن، تاریخ شمسی (جلالی)

## 🧰 پشتهٔ فناوری

| لایه | فناوری |
|---|---|
| فرانت‌اند و سرور | Next.js (App Router) + React 19 + TypeScript |
| رابط کاربری | Tailwind CSS 4 + shadcn/ui + Radix UI |
| داده | Prisma ORM + SQLite |
| OCR و اسناد | Tesseract (fas/eng) + pdfjs-dist + pdf-lib + sharp |
| هوش مصنوعی | z-ai-web-dev-sdk (دستیار مبتنی بر اسناد) |

## 🚀 راه‌اندازی

پیش‌نیازها: **Node.js 20+** یا **Bun**، و **Tesseract OCR** روی سیستم (`tesseract-ocr` و بستهٔ زبان فارسی در صورت نیاز).

```bash
# ۱) نصب وابستگی‌ها
bun install        # یا: npm install

# ۲) تنظیم متغیرهای محیطی
cp .env.example .env

# ۳) ساخت دیتابیس
npm run db:generate
npm run db:push

# ۴) اجرای سرور توسعه
npm run dev        # http://localhost:3000

# ۵) اجرای پردازشگر پس‌زمینه (OCR و استخراج) در ترمینال جداگانه
npm run worker
```

دادهٔ اولیهٔ نمونه (پروژه، اسناد و کاربران آزمون):

```bash
bun scripts/seed.ts
```

اسکریپت‌های آزمون و ابزارها:

```bash
npm run test:phase-a       # آزمون‌های فاز A
npm run test:phase-b       # آزمون‌های فاز B
bun scripts/e2e-ocr.mjs    # آزمون پایان‌به‌پایان OCR
bun scripts/smoke-assistant.mjs  # آزمون دود دستیار هوشمند
```

## 👤 حساب مدیر

رمز عبور مدیر در مخزن **ذخیره نمی‌شود**. در نخستین راه‌اندازی، حساب مدیر از طریق اسکریپت seed ساخته می‌شود و رمز آن باید بلافاصله از مسیر «مدیریت ← کاربران» تغییر داده شود. فایل `data/initial-admin-credentials.txt` صرفاً محلی است و در `.gitignore` قرار دارد.

ورود دومرحله‌ای (MFA/TOTP) به‌صورت پیش‌فرض غیرفعال است و از مسیر «مدیریت ← تنظیمات» قابل فعال‌سازی است. **در استقرار تولید، فعال‌سازی MFA توصیهٔ جدی است.**

## 🔒 نکات امنیتی

- فایل `.env`، دیتابیس (`db/*.db`)، انبار فایل‌های آپلودی (`data/objectstore`)، قرنطینه و فایل رمز مدیر هرگز وارد مخزن نمی‌شوند.
- توکن‌های دانلود فایل‌ها امضادار و منقضی‌شونده هستند (`src/lib/downloadTokens.ts`).
- کنترل دسترسی نقش‌محور در `src/lib/permissions.ts` و گاردهای مسیرها در `src/lib/guard.ts`.

## 📁 ساختار پروژه

```
src/app/api/          # مسیرهای REST (اسناد، پرونده، کارتابل، MTO، دستیار، گزارش‌ها، مدیریت)
src/components/edc/   # اجزای رابط کاربری سامانه (آپلود، مرکز اسناد، دستیار، گزارش‌ها و ...)
src/lib/              # هستهٔ دامنه: احراز هویت، دسترسی، ذخیره‌سازی، OCR، تنظیمات، حسابرسی
worker/               # پردازشگر پس‌زمینه: OCR، استخراج متن، بلوک عنوان
data/tessdata/        # داده‌های آموزشی Tesseract (فارسی و انگلیسی)
docs/                 # مستندات، ماتریس الزامات، گزارش آزمون‌ها، تصاویر محیط
scripts/              # ابزارهای عملیاتی (seed، پشتیبان‌گیری، بازیابی، آزمون‌های e2e)
tests/                # آزمون‌های فازبندی‌شده
```
